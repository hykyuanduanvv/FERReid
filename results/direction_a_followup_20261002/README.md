## 结果使用边界

- 这是开发与机制验证，不是正式Protocol-2或Protocol-3主表。
- 第1步使用旧的Market+MSMT全部图片训练模型，CUHK03为完整700身份；后续采用Market+MSMT train训练的模型，CUHK03为固定500身份开发验证。47.09与57.07不能直接比较方法优劣。
- a0未获得稳定修复，后续按用户要求停止修复；不将成功种子替代全部种子结果。
- 第4步以独立重载后的统一评测为准；原训练任务在训练完成后的基准检查退出记录保留在说明中，不掩盖工程问题。
- 第5步主结果预先固定lr=1e-4、300步，平均全部3份随机标注×2个优化种子；同时报告lr=1e-3敏感性结果。
- 高域分类准确率、prompt变化或非零梯度均不能独自证明检索适应成功。
- 原分步报告保留实验结束当时的叙述，例如“尚未提交”“下一步未执行”；这些是历史状态。本次只归档结果，未提交报告所引用的新增实验脚本。
