第1步：旧正常 VICP checkpoint 的逐层诊断
日期：2026-10-01（Asia/Shanghai）

状态：已完成并停止；等待用户确认后才进入第2步。未进行新训练、结构替换或正式 P2/P3 实验。

核心结论
旧正常 VICP 的上下文域信息能够到达 query，也能够穿过 Visual Head 保留在 prompt 中。
虽然 query 到 prompt 的相对变化能量从 4.344% 降至 0.399%，prompt 仍能以 96.67% 的准确率区分四个已知域。
因此不能把变化能量占比降低解释成“有效信息丢掉了九成”。目前更值得研究的是：保留下来的变化为何没有形成明显的检索收益。
这与本轮 a0 训练塌缩是两个问题，本步不能解释 a0 的训练因果链。

本步使用 identity 单位来控制配对槽位，不等于此前 image 单位的16张标注预算实验。
固定 eval()、评测预处理、问答索引和答案序列；关闭 TF32；保持 checkpoint 的混合参数精度。
重建生成器与生产 forward 在视觉编码器实际接收的精度上完全一致，最大差异为0。
相同上下文重复3次：最终 query 和 prompt 的最大差异均为0。
固定 batch size 的重复图像特征提取差异为0；不同 batch size 下最大差异约2.57e-4，已记录。

线性探针：固定 token 均值池化，再在训练折拟合 StandardScaler 和16维 PCA，最后拟合 LogisticRegression。
每个域的上下文候选身份划为3个互不重叠的桶；训练/测试身份重叠数与图片路径重叠数都为0。
进行3轮×3折分组评估，每折另做5次训练标签打乱对照。不同轮复用这些桶，结果相关，不当作9次独立实验。
这是四个已知域之间的分类；不能用来证明能识别一个训练中从未出现的新域，或者域信息有助于行人检索。

四、极大激活和诊断性屏蔽
在这个checkpoint上，中间层query确实出现极大激活：hidden-state索引3的最大绝对值为4120，能量最高4维占99.50%。
但Visual Head读取的是最后一层query；该处最高4维仅占总能量19.37%，与中间层的数值状态不同。
最后一个hidden-state还包含最终归一化，所以不能把末层绝对尺度改变直接当作信息丢失。

屏蔽维度由独立的Market1501 train上下文预先选定，为[27,7,1,23]，未使用目标测试标签挑选维度。
仅在最终query读出时诊断性置零这4维，没有修改checkpoint或永久删除参数。
屏蔽后query的rho由4.344%升至4.892%，prompt仅由0.399%变成0.404%；检索变化有正有负。
因此，现有证据不支持直接删除这些维度，也不支持仅为提高rho而修改结构。

五、对后续结构选择的含义
1. 不支持“query完全没读到域信息”：第1层起已经能区分域，最后一层仍能区分。
2. 不支持“Head彻底丢掉域信息”：prompt探针96.67%，远高于打乱标签对照。
3. 支持继续检查“变化对检索的作用方向和训练目标”：特征/排序有响应，但本域优势很小。
4. 尚未证明LLM中间层读出优于最后一层，也没有证据要求现在加入LLM LoRA或FiLM。
5. 本结果来自旧正常checkpoint，不可代替对a0早期训练退化的独立诊断。
