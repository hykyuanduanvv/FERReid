# 方向 A：对比上下文损失与 prompt 蒸馏（2026-10-04）

时间为奥克兰时间（NZDT）。机器为 AutoDL 4×RTX 4090 D：对比损失部分用了 4 张卡，蒸馏部分用了 2 张卡。代码为本分支（基于 `Direction_A` `fd31691`）。目录里只放了日志、CSV、JSON，没有 checkpoint、老师 prompt 权重或图像。

## 一句话结论

1. **对比上下文损失（c0–c7）不成立。** 它确实能把本域和跨域分开一点，但代价是本域本身也变差：生成器靠"把外域 prompt 弄坏"来满足损失，而不是"把本域 prompt 调好"。没有一个配置超过 VPT。
2. **用域专属 VPT 做老师、蒸馏生成器（d1）。** 消除了上下文分支相对 VPT 的掉点（从 −1.7 回到约 0），正式协议下**和 VPT 打平，比原版 VICP 高约 2 mAP**。但上下文仍然没有贡献，specificity 约等于 0。
3. **原因（可行性检查）。** 在源域伪域上，每组单独调的专属 prompt 只比全局 VPT 高约 +0.3 mAP，在种子噪声以内。真实摄像头分组、摄像头对、合成风格域都是这样。老师本身就不比 VPT 强多少，所以学生的上限就是"和 VPT 打平"。源域伪域的留出评测只有 85–97 mAP，没有提升空间。

## 共同设置

- **热启动 VPT（"选项 B"）：** `vpt_dinov2_fold1_3k/val_cuhk03/checkpoint-3000`。它是 DINOv2-B/14、LoRA r=128、triplet+WPA、无 BNNeck，用 Market+MSMT 全部图片训了 3000 步，CUHK03 验证 mAP 54.25。cgain 和正式评测里的"VPT"指的都是它。
- **训练（`plans/common.sh`）：**
  - 数据：`$TUNE_DATA` = Market+MSMT 的 train 部分，验证用 CUHK03 的 500 个身份。
  - 模型：`$C_BASE` = VICP、残差 prompt、`delta_init_std 0`、`--init_from VPT`、`--train_context_only`、`--bnneck False --ce_loss_weight 0`。
  - batch：64 个不重复身份，前 16 个只作上下文；每个 batch 只来自一个域。
  - 训练：300 步，lr 1e-4，每 100 步验证一次。
- **cgain（`scripts/context_gain.py`）：** 在 VIPeR / GRID / i-LIDS 上评测，3 个 split，k=4/16，每种条件抽 5 次上下文，选择单位为图像。
  - own：本域上下文生成的 prompt（表中取 k=16）。
  - cross：其他目标域的上下文生成的 prompt。
  - ref：VPT。
  - **specificity = own − cross**，**gain_vs_ref = own − VPT**，表中都是三个域的平均。
- **正式评测（`scripts/eval_context.py`，`plans/_formal_eval.tasks`）：** 和 9/30 主表同一协议，10 个 split，按身份随机选 k=16，3 个上下文种子。用这个协议重测 VPT，得到 85.2 / 66.4 / 87.7，和 9/30 报告逐位一致。

## 一、对比上下文损失（`plans/dirA_contrast.tasks`、`_main.tasks`、`_extra.tasks`）

损失为 `relu(m + gap_own − gap_cross)`，其中 gap = d(最难正样本) − d(最难负样本)，越低越好。own 是本域上下文生成的 prompt 下的特征，cross 是另一训练域缓存的上下文生成的 prompt 下的特征。

**修改：** 第一次在 GPU 上跑时，24G 显存不够，修了两处：
- 跨域那一路跳过一次算完就丢掉的、带词表 logits 的 ICL LM 前向（`with_icl_loss=False`）。
- 跨域那一路的编码器开梯度检查点（`_encode(checkpoint=True, frozen=...)`）。

修改后前向数值不变；单元测试通过；权重为 0 时和原版逐位一致（`unit_tests_*.txt`）。

| 配置（种子数） | specificity | gain_vs_ref | CUHK03 mAP@300 | 训练末段 cross − own |
|---|---|---|---|---|
| c0 无对比（4） | +0.06 | −1.66 | 51.9 | — |
| c1 w=1、m=0.05（3 个正常 + 1 个坍缩） | +0.29 | −6.09 | 47.4 | 0.01–0.05 |
| c2 m=0.1（2） | +2.61 | −14.55 | 39.0 | 0.07 / 0.08 |
| c3 w=3（2） | +0.91 | −10.41 | 42.2 | 0.03 / 0.07 |
| c4 + EMA（2） | +0.60 | −7.48 | 47.5 | 0.05 / 0.02 |
| c5 摄像头对伪域（2） | +0.01 | −1.87 | 52.5 | 0.00 / 0.00 |
| c6 LoRA + detach（2） | +0.42 | −6.74 | 49.0 | 0.05 / 0.03 |
| c7 LoRA 不 detach（2） | −0.25 | −5.04 | 46.9 | 0.13 / 0.14 |

- **主问题不成立：** c1 相对 c0 的 specificity 只多了 0.24，在噪声内；gain_vs_ref 还掉了 4.4。
- **本域没有变好：** 训练日志里 own 那一侧的 gap 几乎不变（变化在 ±0.03 以内），cross 那一侧稳定变差 0.02–0.08。生成器满足损失的方式是把外域弄坏。
- **c1_s42 坍缩：** 开始几步之内特征标准差就从 0.03 掉到 0.0003，CUHK03 mAP 只剩 0.6。这次 run 的 `ctx_gate` 停在初值 0.10 没动，原因还没查清。
- **c7 和 c6：** c7 在训练批次上分得最开（编码器在"作弊"），但在目标域上 specificity 反而不比 c6 高。

## 二、prompt 蒸馏（`docs/DIRECTION_A_DISTILL.md`）

### 2.1 可行性检查：专属 prompt 能比 VPT 好多少（`scripts/group_prompts.py`，`groups_*/`）

**分组方式：**
- **风格分组：** 按摄像头单元聚类，MSMT 的单元是"摄像头 × 时段"。用预训练 DINOv2 的 CLS 特征取均值，单元之间算余弦距离，做平均连接聚类。约束是每组至少 2 个摄像头、至少 64 个跨摄像头身份。
  - 结果：Market 分 2 组（c00/c02/c05 和 c01/c03/c04）；MSMT 分 4 组，其中 3 组室外，1 组是室内 c10–c12。
  - MSMT 里时段几乎不起作用：同一摄像头的早、中、午三个单元总是聚在一起。
  - 摄像头之间的距离中位数：Market 0.09，MSMT 0.26，室内和室外之间最大 0.67。
- **摄像头对：** 取同时被两个摄像头拍到的人数最多的 10 对。
- **合成风格域：** 在 Market 的同一批身份上施加固定的风格变换，共 8 个域：原图、低分辨率、暗光、低对比、偏蓝、偏黄、模糊、灰度。

**老师和评测：**
- **老师：** 冻结 VPT 的主干和 LoRA，从 VPT 的 prompt 出发，只调 prompt。用该组调优身份的全部图片，每个 batch 32 个身份，每人取两张来自不同摄像头的图，用 triplet 损失训 300 步。
- **留出身份：** 每个数据集固定拿 20% 的身份（每组最多取 150 个）做评测，所有组的老师都不会在这些身份上调过。
- **两个指标：**
  - **本组老师 − VPT：** 生成器的收益上限。
  - **本组老师 − 其他组老师：** 用错老师会掉多少。

| 分组 / 老师设置 | 本组 − VPT（平均） | 本组 − 其他老师 | prompt 相对变化 |
|---|---|---|---|
| 风格，lr 1e-3 | −0.39 | +1.83 | 约 3 倍 |
| 风格，lr 3e-4 | +0.27 | +2.33 | 约 1.0 倍 |
| 风格，lr 1e-4，tune_seed 0 / 1 / 2 | **+0.55 / +0.41 / −0.12** | +1.86 / +1.95 / +1.48 | 约 0.4 倍 |
| 风格，lr 1e-4，1000 步 | +0.63 | +2.89 | — |
| 摄像头对，lr 1e-3 / 1e-4 | +0.04 / +0.54 | +2.01 / +1.28 | — |
| 合成风格，lr 1e-4 | +0.56（相对"原图老师"约 +0.9） | +1.23 | 约 0.4 倍 |

风格分组、lr 1e-4、3 个调优种子，"本组 − VPT"逐组结果：

| 组 | Market g0 | Market g1 | MSMT g0 | MSMT g1 | MSMT g2 | MSMT g3（室内） |
|---|---|---|---|---|---|---|
| 平均（标准差） | −0.23（0.35） | −0.22（0.33） | +0.49（0.39） | +0.59（0.06） | +0.39（1.22） | +0.65（1.06） |

- **收益上限很小：** 平均约 +0.3。Market 为负（留出评测已经 96–97，没有空间），MSMT 约 +0.5。同一设置只换调优种子，平均差 0.77、最大差 2.05，所以这个上限和 0 分不开。
- **"用错老师掉的分"主要来自别的老师变差：** 老师调得越猛（学习率越大），本组 − 其他老师越大，但本组 − VPT 反而越小，和对比损失失败的机理相同。
- **合成风格域里只有灰度明显：** 灰度 +1.7 到 +2.1，其余都在 1 分以内。VPT 对暗光、偏色、低分辨率本身已经很鲁棒，在这些合成域上仍有 94–95。

### 2.2 蒸馏训练（`plans/dirA_distill.tasks`）

- **数据：** batch 按风格组划分（`--pseudo_domains camera_group`）。
- **老师：** `groups_style_lr1e-4_s1000/teachers.pt`（不在本仓库里）。
- **损失：**
  - `feat` 模式：每张图学生特征与老师特征的 1 − cos，权重 1。训练开始时约 0.13，结束时降到 0.087。
  - `rel` 模式：batch 内余弦相似度矩阵的 MSE，权重 10。原始值约 0.005。
- **d0：** 同样的分组，但不蒸馏，作为对照。

| run | CUHK03 mAP@300 | specificity | gain_vs_ref（VIPeR / GRID / i-LIDS） | own/cross prompt 余弦 |
|---|---|---|---|---|
| c0_s42（不分组、不蒸馏） | 52.94 | +0.27 | −1.21 | 0.99 |
| d0 s42 / s43（分组、不蒸馏） | 53.46 / 54.00 | −0.13 / −0.03 | −0.30 / −1.47 | 0.99 |
| **d1 s42 / s43（feat 蒸馏）** | **54.69 / 54.29** | +0.06 / +0.08 | **−0.13 / −0.55**（−0.46 / −0.64 / +0.08） | 0.92–0.99 |
| d2 s42（rel 蒸馏） | 53.54 | +0.06 | −0.56 | 0.995 |

正式评测（10 个 split，mAP / Rank-1）：

| 模型 | VIPeR | GRID | i-LIDS | 平均 mAP |
|---|---|---|---|---|
| 原版 VICP DINOv2（9/30，seed 42） | 83.2 / 75.8 | 64.3 / 56.2 | 87.3 / 81.5 | 78.3 |
| 原版 VICP DINOv2（9/30，seed 1） | 81.8 / 74.1 | 62.7 / 54.1 | 86.9 / 81.3 | 77.1 |
| VPT（选项 B，今天重测，和 9/30 一致） | 85.2 / 79.3 | 66.4 / 58.6 | 87.7 / 82.5 | 79.8 |
| **d1 s42** | **85.5 / 79.4** | **67.5 / 59.9** | 87.5 / 82.3 | **80.2** |
| **d1 s43** | 84.6 / 78.3 | 67.1 / 59.8 | 87.2 / 81.7 | 79.6 |

- **相对原版 VICP：** d1 高约 2 mAP（两个种子平均对两个种子平均：+2.6 / +3.8 / +0.3）。不过这部分提升来自 VPT 热启动加蒸馏约束，VPT 本身就比 VICP 高约 2。另外两边训练也不完全一样：原版 VICP 用全部图片训 3000 步，d1 是 VPT 加 300 步、只训上下文分支。
- **相对 VPT：** 两个种子平均 +0.1，打平。GRID 两个种子都高 0.7–1.1，但 VPT 自己在 GRID 上换种子的波动就有 3.9（9/30）。
- **上下文没有贡献：** specificity 约等于 0。不同上下文生成的 prompt 确实更不一样了（余弦降到 0.92），但这种不同对检索没有帮助。

## 下一步（未做）

- **找难的、差异大的训练域：** 让专属老师能明显超过 VPT，生成器才有东西可学。CUHK-SYSU 已经在服务器上按标准划分转换好（`scripts/convert_cuhksysu.py`），实际得到 train 5,532 人 / 15,088 张，query 2,900，gallery 5,447，和 DG-ReID 文献一致。下一步先做它的老师可行性检查。
- **源域伪域的留出评测太容易（85–97）：** 需要更难的评测，比如更大的 gallery，否则上限会被低估。
- **VPT + k 个身份微调，以及"小网络替代 LLM"：** 这两个对照仍未做。
