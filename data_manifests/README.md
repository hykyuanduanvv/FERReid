# 数据划分元数据

本目录只包含图像文件名/相对路径、PID、摄像头与 split 信息，不包含图像。来源为 2026-09-29 服务器上 torchreid 实际使用的划分。

- `viper_splits.json`：20 个划分；主表只用 0–9，10–19 为摄像头互换版本。
- `grid_splits.json`：10 个划分，图库包含干扰图像。
- `ilids_splits.json`：10 个划分，格式为图像 basename；读取器根据名称恢复标签。

VIPeR/GRID 的绝对路径已转换为数据根目录相对路径。用 `scripts/install_splits.py` 检查并恢复到当前机器；脚本保留图片标签/顺序、拒绝无声覆盖不同划分。源训练集与 CUHK03 使用各自固定发布/整理协议，未在此重新生成划分。

这不是内容级泄漏审计；需要图片文件才能检查哈希或近重复。
